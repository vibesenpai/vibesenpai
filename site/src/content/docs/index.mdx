Your agent edits a file it hasn't read. The harness refuses. It reads the file
and tries again. That round trip cost you tokens, it happens in **one session in
three**, and you have never once noticed it — because by the time you read the
reply, it worked.

`vibesenpai` reads the transcripts already on your disk, finds those moments,
prices them, and quotes the turns back to you.

```
  11,000+ tokens discarded on 4 findings · 19 more flagged
    18 sessions · 2,460 edits
```

```
  INACCURATE SELF REPORT
  ────────────────────────────────────────────────────────────────────

  measured   5 times across your sessions, at turns 1050–3493
             "Did you check the corpus?"
  because    Whether the tests pass is not a matter of opinion, so
             it is worth checking rather than trusting. Running the
             command settles it; reading the summary does not.

  ▸ a Stop hook that runs the check instead of trusting the claim
      { "hooks": { "Stop": [{ "hooks": [{ "type": "command",
          "command": "<your test command> || { echo 'not passing' >&2; exit 2; }" }] }] } }

      nothing is written — this is yours to apply.
```
