# Code of Conduct

## In short

Be decent. Assume the other person is trying to get something right.

## Specifically

**Disagree with evidence.** This project settles arguments with measurements and
writes the losing side into [`GRAVEYARD.md`](GRAVEYARD.md). Do that with each
other too: "that fires on 48% of sessions and we cannot show it is waste" is a
good argument; "that is obviously wrong" is not.

**Being wrong is normal here.** The graveyard contains ten deleted detectors, a
result that was buried as a failure and turned out to be worth +11 points, and a
measurement that was confidently wrong for a day. Nobody is going to be
embarrassed for having tried something.

**No harassment**, in issues, PRs, commits or anywhere else. That includes
demeaning comments about someone's experience level, and it includes being
relentlessly negative about someone's work rather than about its results.

## Enforcement

Maintainers may edit, lock, or remove contributions, and may block accounts.
Report concerns privately through
[GitHub Security Advisories](https://github.com/vibesenpai/vibesenpai/security/advisories/new)
if a public issue would be inappropriate.
